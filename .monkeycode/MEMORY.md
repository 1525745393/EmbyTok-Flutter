### Git 提交信息使用中文
- Date: 2026-07-24
- Context: 用户明确指出提交信息格式偏好
- Instructions:
  - 所有 git commit message 必须使用中文描述
  - 必须遵循 Conventional Commits 格式：`<type>: <中文描述>`
  - 常用 type：`fix`（修复）、`refactor`（重构）、`chore`（杂项）、`feat`（新功能）
  - 示例：`fix: 修复 _reinitForNewItem 异步竞态导致并发初始化泄漏`
